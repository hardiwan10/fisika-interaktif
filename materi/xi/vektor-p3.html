Vektor · Pertemuan 3

Operasi Vektor Secara Analitis (Komponen) · Kelas XI

📐 A. Menguraikan Vektor ke Komponen

Vektor A dengan besar |A| dan arah θ (thd sumbu x positif) diuraikan:

Aₓ = |A| · cos θ
A_y = |A| · sin θ

θ diukur dari sumbu X positif berlawanan arah jarum jam.

🔢 B. Penjumlahan & Pengurangan Komponen

Rₓ = Aₓ + Bₓ
R_y = A_y + B_y
|R| = √(Rₓ² + R_y²)
θ_R = arctan(R_y / Rₓ)

Pengurangan: R = A − B → Rₓ = Aₓ − Bₓ, R_y = A_y − B_y.

🔍 C. Contoh Soal

Soal: Vektor A = 5 N, 30°; B = 4 N, 120°. Hitung resultan R!

Penyelesaian:
Aₓ = 5·cos30° = 5·0,866 = 4,33   A_y = 5·sin30° = 5·0,5 = 2,5
Bₓ = 4·cos120° = 4·(−0,5) = −2   B_y = 4·sin120° = 4·0,866 = 3,46
Rₓ = 4,33 + (−2) = 2,33   R_y = 2,5 + 3,46 = 5,96
|R| = √(2,33² + 5,96²) = √(5,43 + 35,52) = √40,95 ≈ 6,4 N
θ_R = arctan(5,96/2,33) ≈ 68,7°

🎯 D. Latihan

1. Urai vektor 10 N, 0° ke komponen.
2. A = 3î + 4ĵ, B = 1î − 2ĵ. Hitung A + B dan |A + B|.
3. Vektor 8 N ke arah 90° (utara). Berapa komponen x dan y-nya?

Kunci

1. Aₓ=10, A_y=0.
2. A+B = 4î+2ĵ, |A+B|=√(16+4)=√20≈4,47.
3. Aₓ=8·cos90°=0, A_y=8·sin90°=8.
